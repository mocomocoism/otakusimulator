Stage 4: Font Awesome local assets

1. Keep the existing assets/js/chart.umd.js and assets/js/html2canvas.min.js from Stage 3.
2. Copy these Stage 4 files over the repository.
3. Run in PowerShell from the repository root:
   powershell -ExecutionPolicy Bypass -File .\setup-fontawesome.ps1
4. Confirm icons are visible in index.html.

Font Awesome version: 6.5.1
